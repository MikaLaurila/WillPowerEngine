# Third-party glTF sample models

These models are used for engine/editor import and rendering tests.

- `car_concept.glb` — Khronos 3D Commerce / Darmstadt Graphics Group sample by Eric Chadwick, CC BY 4.0.
- `commercial_refrigerator.glb` — based on "Commercial Fridge" by Sean Thomas, adapted by Eric Chadwick / Darmstadt Graphics Group, CC BY 4.0.
- `damaged_helmet.glb` — Khronos glTF Sample Assets, CC BY 4.0.

The original copyright and license metadata is embedded in each `.glb` asset.
